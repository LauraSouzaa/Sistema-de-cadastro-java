# Sistema de Cadastro

Projeto simples feito em Java para praticar os conceitos básicos da linguagem.

## Sobre

O programa funciona pelo terminal e possui um menu com duas opções:

1. Cadastrar
2. Sair

No cadastro, o usuário informa:

* Nome
* Idade
* Gênero

Também existem algumas validações para evitar entradas inválidas.

## O que foi usado

* Java
* `while`
* `switch`
* `if`
* `try/catch`
* `String`
* `int`
* `char`
* Métodos
* `Integer.valueOf()`

## Exemplo

```text
===== SISTEMA =====

1. Cadastrar
2. Sair

Escolha uma opção: 1

Digite seu nome completo: João Silva
Digite sua idade com números: 20
Informe seu gênero: Masculino | Feminino | Não informar: M

Cadastro realizado!

Nome: João Silva
Idade: 20
Gênero Masculino.
```
